# Toobit Pump & Dump Scanner (Research Only)

## محتویات
- `app.py`: داشبورد Streamlit برای اسکن قراردادهای USDT-M
- `requirements.txt`: وابستگی‌ها
- `run_windows.bat`: نصب و اجرای سریع در Windows
- `run_mac_linux.sh`: نصب و اجرای سریع در macOS/Linux

## اجرا در Windows
1. Python 3.10 یا جدیدتر نصب کن و گزینه Add Python to PATH را فعال کن.
2. فایل ZIP را Extract کن.
3. روی `run_windows.bat` دوبار کلیک کن.
4. مرورگر روی آدرس محلی Streamlit باز می‌شود.

## اجرا در macOS/Linux
در پوشه پروژه ترمینال باز کن:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## نکات فنی
- فقط از API عمومی Toobit استفاده می‌کند؛ API Key لازم نیست.
- هیچ سفارش یا معامله‌ای ارسال نمی‌کند.
- داده‌های 15m برای ارزهای دارای بیشترین گردش 24h تحلیل می‌شوند.
- OI و عمق دفتر سفارش فقط برای تعداد منتخب بالای فهرست دریافت می‌شوند تا فشار غیرضروری به API وارد نشود.
- تغییر OI با snapshot محلی اجرای قبلی مقایسه می‌شود. در اولین اجرا OI Δ خالی است.
- اجرای مداوم در بازه 5 دقیقه، snapshot OI را به مرور قابل استفاده‌تر می‌کند.
- اگر Toobit ساختار endpoint یا پاسخ API را تغییر دهد، ممکن است نیاز به اصلاح کد باشد.

- حداقل امتیاز نمایش

## منطق امتیاز
این امتیاز یک heuristic شفاف است و احتمال واقعی یا مدل یادگیری ماشین نیست. شکست فقط پس از بسته‌شدن کندل 15 دقیقه‌ای بررسی می‌شود. حجم، RSI، MACD، فشردگی بولینگر، Funding، تغییر OI و عمق 20 سطح دفتر سفارش در امتیاز دخالت دارند.

## هشدار ریسک
برای معاملات واقعی از این جدول به‌تنهایی استفاده نکن. آلت‌کوین‌های کم‌عمق، دستکاری دفتر سفارش، جهش‌های خبری و لیکوییدیشن‌ها می‌توانند باعث سیگنال کاذب و لغزش شدید شوند. ابتدا حداقل چند روز در حالت مشاهده‌ای اجرا و عملکرد سیگنال‌ها را ثبت کن. اهرم بالا توصیه نمی‌شود.
